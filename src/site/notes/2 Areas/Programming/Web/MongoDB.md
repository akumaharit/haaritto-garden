CRUD is an acronym which stands for: Create, Read, Update, Delete
1 Database can have multiple collection.
Each item inside a collection is called document.

You can create / update / delete a document via MongoDB Atlas admin interface (Interface button of the MongoDB that aid in CRUD)
To read or query data, write a object such as `{species: "cat"}`
